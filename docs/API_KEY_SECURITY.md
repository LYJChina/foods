# API Key 与国产大模型接入安全说明

## 1. 当前状态

当前 Demo 不调用任何真实大模型，也不需要模型 API key。预检分析通过后端 `ComplianceAnalyzer` 协议的确定性实现完成，方便在不改变前端契约的前提下替换服务端分析器。

国产大模型服务可选方向包括通义千问、智谱、百度千帆、腾讯混元、火山方舟、DeepSeek 等公开云服务，或满足项目安全要求的本地化部署。具体模型能力、接口地址、鉴权方式、地区可用性、价格和配额必须以厂商最新官方文档与项目采购结果为准，本项目不作预设承诺。

## 2. 不可突破的边界

- 前端不得直接调用模型 API；
- API key 不得出现在 Vue 代码、前端环境变量、浏览器存储、请求参数、测试快照或构建产物中；
- API key 不得写入源码、提交到 GitHub、粘贴到截图或公开文档；
- 日志不得记录 Authorization、Cookie、完整请求体或模型厂商原始错误体；
- 不得向外部模型提交配方、工艺、成本、客户、订单和生产经营数据；
- 不得将模型输出包装为政府结论、认证意见、检验结论或法律意见。

前端只调用平台自己的 FastAPI 接口。FastAPI 在服务端读取密钥、完成数据边界检查、调用模型适配器、收敛厂商错误并返回平台定义的结构化结果。

## 3. 密钥保存方式

本地开发建议仅在未跟踪的后端环境文件或当前 shell 环境中设置变量，例如变量名 `MODEL_API_KEY`、`MODEL_PROVIDER` 和 `MODEL_NAME`。示例值只能写成 `<由部署环境注入>` 等占位符，禁止保存真实密钥。

测试、预发布和生产环境建议使用部署平台的 Secret、容器 Secret、云密钥管理服务或专用密码保险库。应用进程只获得运行所需密钥，开发人员、CI 日志和前端构建均不应读取密钥明文。

建议按环境、项目和用途拆分密钥，授予最小权限，设置轮换周期、调用告警和紧急吊销流程。若密钥疑似泄露，应先在厂商侧吊销或轮换，再清理 Git 历史和缓存；仅删除当前文件不足以消除泄露。

## 4. 服务端接入边界

真实模型接入建议新增 `ComplianceAnalyzer` 的厂商实现，不修改前端请求和响应结构。适配器至少负责：

1. 将平台结构化请求转换为厂商请求；
2. 在调用前执行字段白名单、长度限制和企业核心数据拦截；
3. 设置连接和读取超时；
4. 对超时、限流和临时服务错误执行有限次数、带退避的重试；
5. 校验模型输出并转换为平台 Pydantic 响应模型；
6. 对日志中的密钥、身份信息、文件内容和业务内容做脱敏；
7. 失败时返回稳定的平台错误码，不透传内部实现或厂商敏感信息。

当前预检无需流式输出。只有在后续场景确实需要逐字生成、且前端能正确处理取消、断线和内容安全时，才建议评估 SSE；结构化合规结果应优先采用一次性响应。

## 5. 超时、重试与限流建议

- 服务端为连接与总请求分别设置超时，具体数值通过压测和厂商官方建议确定；
- 只重试幂等或可安全去重的调用，不对参数错误、内容安全拒绝和权限错误盲目重试；
- 重试次数保持有限，并加入指数退避与随机抖动；
- 按调用方、IP、企业和模型预算设置服务端限流与并发上限；
- 为相同请求设计幂等键，避免前端重复点击造成重复计费；
- 记录请求标识、耗时、结果类别和脱敏错误码，不记录密钥与原始敏感内容。

## 6. API 调用链

调用链固定为：浏览器 → 平台 FastAPI → 数据边界检查 → `ComplianceAnalyzer` 实现 → 可选国产模型服务 → Pydantic 结构校验 → 浏览器。

浏览器永远只知道平台 API 地址，不知道模型厂商地址和密钥。模型不可用时，平台应明确返回“服务暂不可用”或切换至经批准的降级规则，不得无提示地伪造模型成功结果。

## 7. 上线前核验清单

- 已核验模型厂商官方文档、服务条款、数据处理条款和部署地域；
- 已完成许可证、采购、网络边界、等保和数据出境相关评审；
- 已确认提交字段白名单、留存期限、删除机制和用户告知；
- 已完成密钥扫描、依赖扫描、接口鉴权、限流、超时和日志脱敏测试；
- 已明确法规数据来源、更新责任、人工复核人与免责声明；
- 已验证供应商不可用、超时、限流、输出结构错误和内容安全拒绝等异常路径。
